# 项目状态探查技能

## 做什么

按固定顺序只读治理文件；只有 `CURRENT.md` 是当前状态真源：

1. `CURRENT.md` → schema、当前任务、状态、批准绑定和下一步；缺失/未知 schema 按 v4.3 失败关闭
2. `BLOCKED.md` → 局部/全局阻塞及待裁决事项
3. `STATUS.md` → 仅作项目背景和阶段摘要，不得覆盖 CURRENT
4. `PROBLEM.md` → 已知问题与红线，不得自行改变批准范围
5. 缺哪个文件就标注"未建立"，不要猜

## 输出（≤15 行）

- 项目状态一句话
- 当前任务与下一步
- 阻塞项（有/无，有则列条目）
- 红线提醒（与本次相关的）

## 注意

- 这是只读操作；探查本身不修改任何文件
- 文件过期（日期与现状明显不符）要提示用户治理文件需要更新
